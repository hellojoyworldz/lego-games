## 요약 (Executive Summary)

**Perfect Ten**은 “선택한 숫자의 합이 정확히 10”이라는 단 하나의 규칙 위에, **물리 쌓임·제한 시간·위험선**을 겹친 웹 미니게임이다. 플레이어는 1~9 숫자가 적힌 컬러 구슬을 터치해 조합을 만들고, 성공할 때마다 점수와 시간을 회복한다. 동시에 구슬은 중력으로 쌓이고 타이머는 줄어들어, **계산 퍼즐**과 **공간 서바이벌**을 동시에 경험하게 된다.

- **3초 이해**: “합이 10” — 누구나 즉시 시작 가능
- **15초 긴장**: 15초 시작 타이머 + 위험선 압박으로 짧은 세션 몰입
- **반복 동기**: 콤보 배율, 퍼펙트 클리어(+5,000점), 최고 기록 경쟁

## 1. 게임 개요

### 1.1 한 줄 소개

**숫자 구슬의 합이 정확히 10이 되도록 선택해 터뜨리되, 쌓이는 구슬과 줄어드는 시간을 동시에 견디는 물리 기반 서바이벌 퍼즐.**

### 1.2 컨셉

화면 아래쪽에 1~9 숫자가 적힌 컬러 구슬이 물리 엔진으로 쌓여 있다. 플레이어는 구슬을 터치해 선택(토글)하고, **선택 합계가 정확히 10**이 되면 해당 구슬들이 폭발하며 사라진다. 성공할 때마다 점수와 시간을 회복하지만, 구슬은 계속 위에서 떨어지고 **위험선(Deadline)** 은 점점 가까워진다.

단순한 “합이 10” 규칙 위에 **물리 쌓임 · 시간 압박 · 콤보 · 전략 버튼(힌트·구슬 추가·셔플)** 을 겹쳐, “계산만 하는 퍼즐”이 아니라 **압박 속에서 빠르게 판단하는 액션 퍼즐** 경험을 제공한다.

### 1.3 코어 루프

```
관찰 → 선택 → 합계 판단 → (성공) 제거·보상·콤보
                      ↓ (실패) 콤보 파괴·행동 불능
         시간 감소 + 구슬 누적 + 위험선 접근
                      ↓
              재도전 또는 게임 오버
```

### 1.4 기획 의도 — 해결하려는 문제

| 문제                                         | Perfect Ten의 해답                                                  |
| -------------------------------------------- | ------------------------------------------------------------------- |
| 웹 미니게임은 3초 안에 규칙을 이해해야 한다  | “합이 10” — 초등 수학 수준의 직관적 규칙                            |
| 짧은 세션에서도 몰입감이 필요하다            | 물리 쌓임 + 위험선 + 타이머로 지속적 긴장 유지                      |
| 한 번 플레이하고 끝나기 쉽다                 | 콤보·퍼펙트 클리어·최고 기록 경쟁으로 반복 동기 부여                |
| 모바일 웹은 조작·사운드 품질이 떨어지기 쉽다 | 큰 터치 영역, 햅틱·BGM/SFX 피드백 등 모바일 UX를 기획 단계부터 반영 |

### 1.5 타깃 플레이어

| 페르소나              | 특성                    | 기대 경험                                 |
| --------------------- | ----------------------- | ----------------------------------------- |
| **킬링타임러**        | 지하철·대기 시간 1~2분  | 규칙 즉시 이해, 한 판 끝나면 바로 재도전  |
| **퍼즐 애호가**       | 숫자 조합·최적화를 즐김 | 4~5개 조합, 퍼펙트 클리어, 콤보 유지 도전 |
| **하이스코어 추구형** | 기록 갱신·숙련에 동기   | 콤보 배율 극대화, 힌트 없이 클리어        |

## 2. 핵심 규칙

### 2.1 승리·패배 조건

| 구분                         | 조건                                                                 |
| ---------------------------- | -------------------------------------------------------------------- |
| **진행 중 (승리 개념 없음)** | 제한 시간 내 최대 점수·최장 생존을 목표로 무한 진행                  |
| **패배 ①**                   | 제한 시간이 **0초**가 되면 게임 오버                                 |
| **패배 ②**                   | 구슬 더미 최상단이 **위험선**을 넘어 **3초** 이상 유지되면 게임 오버 |
| **자진 종료**                | 일시정지 → 게임 종료 선택 시 결과 화면으로 이동                      |

### 2.2 기본 규칙

1. 필드에 **1~9 숫자**가 적힌 구슬이 배치된다. (시작 시 약 20개, 벌집형 그리드)
2. 구슬을 터치하면 **선택 / 선택 해제(토글)** 된다. 선택 합계는 화면 상단에 실시간 표시된다.
3. 선택 합계가 **정확히 10**이면 해당 구슬들이 제거되고 **점수·시간 보너스**를 받는다.
4. 선택 합계가 **10을 초과**하면 실패 — 선택 해제, **콤보 초기화**, 약 **0.3초 행동 불능(패널티)** 발생.
5. 10 성공 시 위에서 **새 구슬 2개**가 낙하하여 필드가 갱신된다.
6. 생존 시간이 길어질수록 **타이머 감소 속도**가 점점 빨라진다.

### 2.3 점수·시간 보상

| 제거 구슬 수 | 예시 조합                       | 기본 점수 | 시간 보너스 |
| ------------ | ------------------------------- | --------- | ----------- |
| 2개          | 3 + 7, 4 + 6                    | 100       | +2초        |
| 3개          | 2 + 3 + 5                       | 300       | +2초        |
| 4개          | 1 + 2 + 3 + 4                   | 850       | +4초        |
| 5개 이상     | 1 + 2 + 3 + 4 + 0… (1~9만 사용) | 1,800     | +7.5초      |

**콤보 배율**: 연속 10 성공 시 획득 점수 = 기본 점수 × 콤보 수  
→ 예) 3콤보 상태에서 4개 조합(850점) 성공 → **2,550점**

**퍼펙트 클리어**: 필드의 **모든 구슬**을 제거하면  
→ **+5,000점**, **+10초**, 무지개 파티클 연출 후 **새 필드**로 재시작 (게임은 계속)

**시간 상한**: 회복으로 늘어난 제한 시간은 최대 **30초**까지

### 2.4 콤보 규칙

- 10 성공 후 **3초 이내**에 다시 10을 만들면 콤보 유지
- 10 초과 실패 시 콤보 **즉시 리셋**
- **2콤보부터** 화면 중앙 콤보 팝업 + 피치 상승 효과음 + 햅틱으로 성취감 강화
- 결과 화면에 **최대 콤보** 기록 표시

### 2.5 난이도 상승 (내재적)

| 요소                  | 설명                                                    |
| --------------------- | ------------------------------------------------------- |
| **시간 감소 가속**    | 생존 시간이 길어질수록 타이머가 조금씩 더 빠르게 줄어듦 |
| **매치 후 구슬 보충** | 10 성공마다 위에서 새 구슬 2개 낙하                     |
| **위험선 압박**       | 구슬이 쌓일수록 위험선 근접 → 3초 초과 시 게임 오버     |
| **공간 제약**         | 물리 충돌로 구슬이 엉키면 원하는 숫자 선택이 어려워짐   |

## 3. 플레이 방식

### 3.1 조작

| 입력             | 동작                                                        |
| ---------------- | ----------------------------------------------------------- |
| 구슬 터치 / 클릭 | 선택 / 선택 해제                                            |
| 💡 **힌트**      | 10을 만들 수 있는 조합 1개 강조 (쿨다운 3초, 4초간 표시)    |
| ＋ **구슬**      | 위에서 구슬 2개 추가 낙하 (더미가 위험선에 가까우면 비활성) |
| 🔄 **셔플**      | 남은 구슬 위치·속도 재배치                                  |
| ⏸ **중지**       | 일시정지 (계속하기 / 게임 종료)                             |
| 🔊 **음소거**    | BGM·효과음 ON/OFF (모든 화면 공통)                          |

**자동 힌트**: 10초간 10 성공이 없으면 힌트가 자동으로 표시된다.

### 3.2 플레이 흐름

```
[인트로] → 규칙 확인 → Perfect Ten 시작
    ↓
[플레이] → 15초 타이머 시작, 구슬 필드 등장
    ↓
[선택] → 합계 실시간 확인 (10 / 10 미만 / 10 초과)
    ↓
[10 성공] → 폭발 연출 + 점수·시간 회복 + 콤보 + 신규 구슬 2개 낙하
    ↓
[압박 누적] → 더미 상승 + 타이머 감소 + BGM 긴급 모드
    ↓
[종료] → 시간 소진 OR 위험선 3초 초과 OR 자진 종료 → 결과 → 재도전
```

### 3.3 플레이 시나리오 (예시)

**시나리오 A — 안정적 생존**  
타이머 8초, 필드에 3·7·2·5·1 등이 보인다. 플레이어는 **3 + 7** (2개)로 빠르게 10을 만든다. +100점, +2초. 리스크는 낮지만 점수도 적다.

**시나리오 B — 고점수 도박**  
콤보 4, 타이머 5초. **1 + 2 + 3 + 4** (4개)를 노리면 850 × 4 = **3,400점** + 4초. 선택 중 실수로 11이 되면 콤보가 끊기고 0.3초 행동 불능.

**시나리오 C — 위험선 위기**  
구슬 더미가 위험선 바로 아래. **셔플**로 조합 가능성을 재배치하거나, **구슬 추가**로 새 숫자를 받되 더미 증가 리스크를 감수한다. 3초 넘기면 게임 오버.

**시나리오 D — 퍼펙트 클리어**  
마지막 **6 + 4**로 필드를 비운다. “PERFECT CLEAR!” 배너, +5,000점, +10초, 새 필드 20개 스폰. “한 판 더” 동기가 최고조.

### 3.4 전략적 선택

| 선택           | 이점                             | 리스크                                |
| -------------- | -------------------------------- | ------------------------------------- |
| **2~3개 조합** | 빠른 처리, 실수 적음             | 낮은 점수·시간 회복                   |
| **4~5개 조합** | 높은 점수·시간, 콤보 배율 극대화 | 선택 실수 → 콤보 파괴                 |
| **구슬 추가**  | 조합이 없을 때 새 기회           | 더미 증가, 위험선 접근                |
| **셔플**       | 엉킨 구슬 재배치                 | 짧은 혼란, 타이머는 계속 감소         |
| **힌트**       | 막힘 해소                        | 쿨다운 3초, 숙련자에겐 점수 손해 체감 |

## 4. 주요 재미 요소

### 4.1 즉각적 이해 + 깊은 숙련

- 규칙은 “합이 10” 하나지만, **어떤 조합을 언제 쓸지**, **구슬을 추가할지 말지**에 따라 결과가 달라진다.
- 초보는 2개 조합으로 생존, 숙련자는 5개 조합·퍼펙트 클리어·10콤보+를 노린다.

### 4.2 물리 쌓임의 긴장감

- 구슬이 중력·충돌·튕김으로 자연스럽게 쌓여 **공간 압박**이 생긴다.
- 위험선을 넘기 직전 **“WARNING!”** 연출과 비네팅으로 한순간의 판단이 승패를 가른다.

### 4.3 콤보 & 퍼펙트 클리어의 도파민

- 연속 성공: 콤보 팝업, 피치 상승 SFX, 햅틱, HUD 콤보 배지
- 필드 전멸: “PERFECT CLEAR!” 대형 배너 + 무지개 파티클 + 5,000점 + 10초

### 4.4 오디오·시각 몰입

| 영역          | 내용                                                           |
| ------------- | -------------------------------------------------------------- |
| **BGM 3단계** | 일반 → 긴급(5초 이하) → 패닉(3초 이하), BPM·필터 변화          |
| **합성 SFX**  | 탭·성공·실패·콤보·퍼펙트·게임오버 각각 고유 사운드             |
| **연출**      | 화면 흔들림, 위험 비네팅, 파티클, 플로팅 텍스트 (+점수, +시간) |
| **햅틱**      | 탭·콤보·퍼펙트·실패·게임오버 (모바일)                          |

### 4.5 반복 플레이 동기

- 결과 화면: **최종 점수 / 최대 콤보 / 생존 시간**
- “한 판 더” — 더 높은 콤보, 퍼펙트 클리어, 무힌트 클리어 도전

## 5. 차별화 포인트

### 5.1 기존 “합이 10” 게임과의 비교

| 일반 숫자 퍼즐             | Perfect Ten                                  |
| -------------------------- | -------------------------------------------- |
| 고정 그리드에서 숫자 선택  | **물리 엔진** 기반 구슬 쌓임                 |
| 시간 제한 없음 또는 느슨함 | **15초 시작 + 지속 감속** 타이머 (상한 30초) |
| 실패 = 선택만 초기화       | **10 초과 = 콤보 파괴 + 행동 불능**          |
| 패배 조건 단일             | **시간 소진 + 위험선 3초 초과** 이중 패배    |
| 수동 진행만                | **힌트·구슬 추가·셔플** 전략 버튼            |
| 정적 UI                    | BGM 긴급 모드, 콤보 팝업, 퍼펙트 클리어 연출 |

### 5.2 핵심 차별화 3가지

1. **공간 + 숫자 이중 퍼즐**  
   “어떤 숫자를 고를까”와 “구슬이 어디에 쌓였는가”를 동시에 고려해야 한다.

2. **압박 기반 게임 템포**  
   타이머·위험선·BGM 긴급 모드가 겹치며 15초~2분 세션 안에서도 완결된 긴장 곡선이 형성된다.

3. **웹 친화적 설계**  
   설치 없이 URL 접속 즉시 플레이. PC·모바일 세로 화면 모두를 전제로 한 조작·UI 배치.

## 6. 화면 구성

### 6.1 화면 흐름

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  1. 인트로    │ ──→ │  2. 플레이    │ ──→ │  3. 결과     │
│  타이틀·규칙  │     │  HUD+캔버스  │     │  점수·재도전 │
└─────────────┘     └─────────────┘     └─────────────┘
                           │
                    ┌──────┴──────┐
                    │  일시정지    │
                    │  오버레이    │
                    └─────────────┘
```

### 6.2 화면별 상세 구성

#### (1) 인트로 화면

```
┌──────────────────────────────┐
│                        🔊    │
│           🔟                 │
│      PERFECT TEN             │
│  합계가 정확히 10이 되게!      │
│  🔥 콤보 시스템 안내           │
│                              │
│   [ Perfect Ten 시작 ⚡ ]     │
└──────────────────────────────┘
```

- 게임 로고 **PERFECT TEN**, 한 줄 규칙, 콤보 소개
- **Perfect Ten 시작** 버튼
- 우상단 음소거 토글

#### (2) 플레이 화면

```
┌──────────────────────────────┐
│ SCORE: 0    SURVIVAL: 00:00  │
│ [████████████░░░░] TIME 15s  │
│ COMBO                        │
├──────────────────────────────┤
│      선택 합계: 3 + 7 = 10   │
├──────────────────────────────┤
│ - - - - 위험선 (Deadline) - -│
│     ●3    ●7    ●2           │
│        ●5    ●1    ●4        │
│   (물리 구슬 캔버스 영역)      │
├──────────────────────────────┤
│ ⏸중지  💡힌트  ＋구슬  🔄셔플 │
└──────────────────────────────┘
```

| 영역          | 구성 요소                                                     |
| ------------- | ------------------------------------------------------------- |
| **상단 HUD**  | SCORE, SURVIVAL(mm:ss), 타이머 바, 남은 시간(초), COMBO 배지  |
| **선택 합계** | `3 + 7 = [ 10 ]` 형식, 10 / 10 미만 / 10 초과 색상 구분       |
| **캔버스**    | 위험선, 물리 구슬, 콤보 팝업, PERFECT CLEAR 배너, 위험 비네팅 |
| **하단 독**   | 중지 · 힌트 · 구슬 · 셔플 (엄지존 배치)                       |

#### (3) 일시정지 오버레이

- **PAUSED** 타이틀, “계속하기 ▶”, “게임 종료”

#### (4) 결과 화면

```
┌──────────────────────────────┐
│        GAME OVER             │
│   (종료 사유 한 줄)            │
│ ┌──────────────────────────┐ │
│ │ 최종 점수        12,450  │ │
│ │ 최대 콤보        5COMBO  │ │
│ │ 최종 생존 시간   01:23   │ │
│ └──────────────────────────┘ │
│   [ 다시 도전하기 🔄 ]        │
└──────────────────────────────┘
```

- 종료 사유: 시간 초과 / 위험선 넘침 / 자진 종료
- **다시 도전하기** → 인트로 또는 즉시 재시작

### 6.3 UI/UX 원칙

- **모바일 퍼스트**: 세로 화면, 큰 터치 영역, 하단 엄지존 버튼
- **즉시 피드백**: 선택·성공·실패마다 색·사운드·진동 동시 반응
- **정보 과부하 방지**: HUD는 점수·생존·타이머·콤보 4가지만, 나머지는 연출로 전달
- **접근성**: 선택 합계를 수식으로 표시해 계산 부담 최소화
